Evidence before authority

Un agente no debería obtener autoridad sólo porque afirma que una tarea está “terminada”. RUMBO separa claim, evidence y gate.

RM-004Public-safe

La regla

Una afirmación relevante sólo puede promoverse dentro del alcance que realmente está respaldado por evidencia suficiente y una política de gates explícita.

Caso negativo

claim:
  TASK_COMPLETE=PASS

evidence:
  "Todo salió bien"

gates:
  [sin política estructurada]

=> NO_GO / UNPROVEN

Caso positivo

claims:
  READY=PASS
  PACKAGE_SHA256=abc123

evidence:
  READY=PASS
  PACKAGE_SHA256=abc123
  TESTS=PASS

gates:
  GATES=NONE

=> GO / PROVEN

Estado técnico mostrado

Global production: NO_GO

Frontera de autoridad

PASS != autorización global

La prueba semántica no implica aceptación canónica global, aprobación de terceros, publicación en un directorio externo ni autorización de producción.

Qué intenta demostrar este caso

Que una capa independiente puede distinguir entre “el agente lo dijo” y “existe evidencia suficiente para aceptar esa afirmación dentro de un scope concreto”.
